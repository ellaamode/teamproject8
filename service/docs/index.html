API · DB 문서

이 문서는 손으로 쓰지 않았습니다. API 부분은 FastAPI가 만드는 OpenAPI 명세(Swagger와 같은 원천)와 실제 호출 결과에서, DB 부분은 PostgreSQL 카탈로그에서 자동으로 생성했습니다(python -m tools.gen_docs). 그래서 코드·DB와 어긋나지 않습니다.

API 설명 문서

모든 API는 조회 전용 GET, 응답은 JSON(UTF-8), 날짜는 ISO 8601. 오류는 {"detail": …} 형식 — 404 없는 대상 · 422 허용하지 않는 입력값 · 503 DB 연결 실패. 응답에 Cache-Control: max-age=300.
